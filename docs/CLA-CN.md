# Tinode 个人贡献者许可协议

为了明确来自任何个人或实体的贡献所授予的知识产权许可，[Tinode LLC](https://tinode.co) 必须有每位贡献者签署的贡献者许可协议（"CLA"），表明同意以下许可条款。此许可是为了保护您作为贡献者以及保护 Tinode LLC；它不会改变您将贡献用于任何其他目的的权利。

您接受并同意以下关于您提交给 Tinode 的现有和未来贡献的条款和条件。除本协议授予 Tinode LLC 和 Tinode LLC 分发的软件接收者的许可外，您保留对您的贡献的所有权利、所有权和利益。

1. 定义。
"您"（或"您的"）应指与本协议与 Tinode LLC 达成协议的版权所有者或版权所有者授权的法律实体。对于法律实体，做出贡献的实体与控制该实体、受该实体控制或与该实体共同控制的所有其他实体被视为单一贡献者。就本定义而言，"控制"指（i）直接或间接导致该实体的方向或管理的权力，无论是通过合同或其他方式，或（ii）拥有百分之五十（50%）以上的流通股，或（iii）该实体的实益所有权。
"贡献"应指任何原创作者作品，包括对现有作品的任何修改或添加，由您有意提交给 Tinode LLC 以包含在 Tinode LLC 拥有或管理的任何产品中或作为其文档（"作品"）。就本定义而言，"提交"指发送给 Tinode LLC 或其代表的任何形式的电子、口头或书面通信，包括但不限于在电子邮件列表、源代码控制系统和由 Tinode LLC 管理或代表 Tinode LLC 管理的问题跟踪系统上的通信，用于讨论和改进作品，但不包括明显标记或由您书面指定为"非贡献"的通信。

2. 版权许可授予。
在遵守本协议条款和条件的前提下，您特此授予 Tinode LLC 和 Tinode LLC 分发的软件接收者永久、全球、非独占、免费、免版税、不可撤销的版权许可，以复制、准备衍生作品、公开展示、公开表演、再许可和分发您的贡献和此类衍生作品。

3. 专利许可授予。
在遵守本协议条款和条件的前提下，您特此授予 Tinode LLC 和 Tinode LLC 分发的软件接收者永久、全球、非独占、免费、免版税、不可撤销（本节规定除外）的专利许可，以制造、已制造、使用、要约销售、销售、进口和以其他方式转移作品，此类许可仅适用于您的贡献单独或与该贡献所提交的作品组合必然侵权的可许可专利权利要求。如果任何实体对您或任何其他实体提起专利诉讼（包括诉讼中的反诉或交叉索赔），声称您的贡献或您贡献的作品构成直接或贡献性专利侵权，则根据本协议授予该实体的该贡献或作品的任何专利许可应于该诉讼提起之日终止。

5. 您声明您的每个贡献都是您的原创作品（见第 7 节关于代表他人提交）。您声明您的贡献提交包含您个人知道的与您贡献的任何部分相关的任何第三方许可或其他限制（包括但不限于相关专利和商标）的完整详情。
